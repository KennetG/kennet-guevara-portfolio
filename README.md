# Kennet Guevara — Personal website

A concise, responsive portfolio built with Vite and plain JavaScript/CSS. The design uses an editorial technical-dossier language rather than a conventional dashboard aesthetic.

## Run locally

```bash
pnpm install
pnpm run dev
```

## Production build

```bash
pnpm run build
```

Content is intentionally limited to professional experience, development interests, selected credentials, email, LinkedIn, and country-level location.
